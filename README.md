# NEXUS.DEV — портфолио-сайт

Тёмный «терминальный» сайт-визитка для AI/ML full-stack разработчика: услуги с ценами,
кейсы (веб / мобильные / AI-системы и админки), портфолио для стоков (фото-коллекции и
видео-коллекция), блок подтверждения авторства для верификации на маркетплейсах и форма
приёма заказов через Telegram / почту.

Стек: **Vite + React 19 + TypeScript + Tailwind CSS 4**. Собирается в статику, деплоится
на GitHub Pages через GitHub Actions. Шрифты (Inter, JetBrains Mono) захостингованы локально
— сторонних запросов нет.

```bash
npm ci          # зависимости
npm run dev     # локальный сервер  (http://localhost:5173)
npm run build   # продакшн-сборка в dist/
npm run preview # посмотреть собранную версию
npm run typecheck
```

## 1. Что править

**Всё содержимое сайта лежит в одном файле: [`src/data/content.ts`](src/data/content.ts).**

### Бренд и контакты (секция `profile`)

| Поле | Что это | Где увидите |
| --- | --- | --- |
| `brand` | название в шапке/футере | `NEXUS.DEV` |
| `owner` | ваше имя или ник | футер |
| `telegram`, `telegramLabel` | ссылка и @ник | все кнопки «Заказать» |
| `email` | почта | блок контактов, кнопка `mailto:` |
| `github`, `youtube`, `behance` | соцсети (пустая строка = скрыть) | футер/контакты |
| `stockAuthorLinks` | ссылки на страницы автора на стоках | блок «Профили автора» |

> ⚠️ Сейчас в `profile` стоят заглушки (`NEXUS.DEV`, `Your Name`, `@your_handle`,
> `hello@your-domain.com`) — замените на свои. Это первое, что проверят на верификации.

### Услуги и цены (секция `ui.services.items`)

Цены стоят так, как согласовано: AI-ролики **от $100**, мобильные приложения **от $150**,
MLOps/DevOps **от $30/час**, паки картинок и видео-пресетов **от $50**; остальные позиции —
«по запросу». Каждая услуга — объект с `title`, `desc`, `price`, `priceMeta`, `points`;
`featured: true` поднимает карточку в крупный блок с чек-листом.

### Кейсы (секция `works`)

Группы: `web` — веб-приложения и платформы, `ai` — AI-системы, чатботы и админки,
`mobile` — Flutter-приложения. У каждой карточки есть `metric` (например
«12k активных пользователей»), `stack`, `tags` и опциональный `link` на живой сайт/кейс.

### Стоковые коллекции (секция `galleries`)

- `photo-*` — фото-коллекции (сейчас 3 штуки по 9 кадров),
- `video-*` — видео-коллекция (1 штука, 6 клипов, у клипов есть `duration`).

Метаданные (`resolution`, `formats`, `meta`) видны верификаторам — заполните их под реальные
файлы.

## 2. Картинки

Все превью сейчас — сгенерированные заглушки в `public/previews/`. Замените их своими
файлами (jpg/png/webp) либо положите рядом и поправьте `src` в `content.ts`:

```ts
{
  src: '/previews/photo-neon-01.svg',   // ← /previews/ваш-файл.jpg
  ...
}
```

Пропорции: **16:10** (1600×1000) для фото и обложек кейсов, **16:9** (1600×900) для
видео-клипов. Заглушки можно перегенерировать:

```bash
node scripts/gen-placeholders.mjs
```

## 3. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (публичный или приватный — для Pages нужен платный план
   для приватных репозиториев) и закоммитьте папку `portfolio` в его корень:

   ```bash
   cd portfolio
   git init
   git add .
   git commit -m "Portfolio site"
   git branch -M main
   git remote add origin git@github.com:<ваш-ник>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

3. Вкладка **Actions** покажет запуск `Deploy to GitHub Pages`. Через минуту сайт будет
   доступен по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

   Воркфлоу сам подставляет правильный базовый путь (`/` для репозитория
   `<ник>.github.io`, иначе `/имя-репозитория/`), так что ссылки и картинки не сломаются.

4. Дальше достаточно `git push` — каждый коммит в `main` публикует новую версию.

### Проверка после деплоя

- [ ] открылся по ссылке, не белый экран;
- [ ] переключатель **EN / RU** работает и запоминается;
- [ ] галереи открываются в лайтбоксе (клик / стрелки / `Esc`);
- [ ] кнопки Telegram и почты ведут на ваши настоящие контакты;
- [ ] в блоке «Профили автора» появились реальные ссылки на страницы автора.

## 4. Структура проекта

```
portfolio/
├── .github/workflows/deploy.yml   # деплой на GitHub Pages
├── public/previews/               # превью галерей и обложки кейсов
├── scripts/gen-placeholders.mjs   # генератор заглушек
└── src/
    ├── App.tsx                    # сборка секций
    ├── i18n.tsx                   # контекст EN/RU + выбор языка
    ├── index.css                  # дизайн-токены и компонентные стили
    ├── data/content.ts            # ← всё содержимое сайта
    └── components/
        ├── Nav.tsx Hero.tsx Metrics.tsx Capabilities.tsx Services.tsx
        ├── Work.tsx Stock.tsx Lightbox.tsx Process.tsx Faq.tsx
        ├── Contact.tsx Footer.tsx ui.tsx
```

## 5. Если нужен свой домен

В корне репозитория положите файл `CNAME` с содержимым вида `www.example.com`, затем
**Settings → Pages → Custom domain**. Описания смены домена и обновления цен/контактов
для перепроверки на маркетплейсах — в `src/data/content.ts`, пересборка не нужна.
